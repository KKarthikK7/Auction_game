# Sunrisers Hyderabad · Squad

A fan-made team profile page for a Sunrisers Hyderabad dream XI, built with React, Vite and Tailwind CSS.

- Sunrise hero with animated sun rays
- Player cards with 3D tilt and cursor spotlight
- Role filters, search, and a player profile popup
- Playing XI and extra squad sections
- 2016 champions banner and team records

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Edit the squad

All players live in `src/data/players.js`. Add `image: '/players/<file>'` to show a photo
from `public/players/`; players without one show their initials. Add `reserve: true` to put
a player in the extra squad.

Fan project, not affiliated with Sunrisers Hyderabad or the IPL. Player photos belong to their owners.
